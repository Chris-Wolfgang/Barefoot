# Exit codes

Generated from `ExitCode` and `ExitCodes` in `Wolfgang.Barefoot.Core`. Do not edit this file by hand;
change the code and run `scripts/Update-GeneratedDocs.ps1`. A test fails when the two differ.

The three command-line tools share one numbering (ADR 0007), so a code never means two things.

| Code | Name | Meaning | Used by | The scheduled job |
|---|---|---|---|---|
| 0 | `Ok` | Done. | `bf-scraper`, `bf`, `bf-maint` | continues |
| 1 | `Failed` | The verb failed: a migration failed, or an exception nothing handled. | `bf-scraper`, `bf`, `bf-maint` | continues |
| 2 | `Partial` | Finished with warnings; some items did not complete. | `bf-scraper`, `bf` | continues |
| 3 | `BreakerTripped` | The scraper stopped the run because the site was unhappy; resume later. | `bf-scraper` | continues |
| 4 | `Usage` | Bad arguments or configuration. | `bf-scraper`, `bf`, `bf-maint` | continues |
| 5 | `VersionMismatch` | The API is too old or too new for this binary; the message says which side to update. | `bf-scraper`, `bf` | stops |
| 6 | `DataLossNotConfirmed` | A downgrade would lose data and `--confirm-data-loss` was not given. | `bf-maint` | continues |
| 7 | `ApiUnavailable` | The API could not be reached within the retry budget. | `bf-scraper`, `bf` | stops |
| 8 | `DatabaseUnavailable` | The database could not be reached within the retry budget. | `bf-scraper`, `bf`, `bf-maint` | stops |
| 9 | `QuotaExhausted` | The monthly free database allowance is used up. | `bf-scraper`, `bf`, `bf-maint` | stops |
| 10 | `Refused` | The tool will not act, for example on a schema newer than the build. | `bf-maint` | continues |
| 11 | `MissingMigration` | `migrate --status` found the database behind this build: a migration is not applied. | `bf-maint` | continues |

The scheduled job runs its steps in order and reads each step's exit code. It stops on a code
marked *stops*, because no later step can work, and goes on to the next step otherwise: after a
partial run or a tripped breaker the digests for what did complete are still sent.
